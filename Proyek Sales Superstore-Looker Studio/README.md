# Superstore Shipping Performance Dashboard
Dashboard interaktif ini dibuat menggunakan Looker Studio untuk menganalisis performa pengiriman dan efisiensi logistik berdasarkan dataset Sample Superstore.

## 🔗 Link Akses Dashboard
[Klik di sini untuk melihat Live Dashboard di Looker Studio](https://datastudio.google.com/reporting/c0b0ccae-0753-47ac-9177-258855a7717d)

## 📊 Fitur Utama
- **Sales & Shipping Overview:** Memantau total pesanan, status keterlambatan (*On Time/Delayed*), dan rata-rata waktu proses pengiriman.
- **Regional Analysis:** Menganalisis performa pengiriman berdasarkan region dan *Ship Mode* (Standard, Second Class, First Class, Same Day).
