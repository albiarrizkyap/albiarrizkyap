# Proyek Machine Learning
Repository ini berisi kumpulan proyek **Machine Learning** yang dikerjakan sebagai bagian dari kegiatan perkuliahan.

Proyek dalam folder ini mencakup implementasi konsep, metode, dan algoritma pembelajaran mesin yang dipelajari selama perkuliahan. Setiap proyek dilengkapi dengan proses pengolahan data, implementasi metode, evaluasi, serta analisis hasil.

## Mata Kuliah
Proyek dalam repository ini berkaitan dengan mata kuliah:
* **MA3053 – Pembelajaran Mesin**
* **IF3270 – Pembelajaran Mesin**

## Tujuan
Folder ini digunakan untuk mendokumentasikan proses pembelajaran dan implementasi materi Pembelajaran Mesin dalam bentuk proyek.

Tujuan utama pengerjaan proyek dan praktikum meliputi:
* Memahami konsep dasar dan metode pembelajaran mesin
* Mengimplementasikan algoritma Machine Learning menggunakan Python
* Melakukan preprocessing dan eksplorasi dataset
* Membangun dan melatih model Machine Learning
* Melakukan evaluasi terhadap model
* Membandingkan performa beberapa metode
* Menganalisis hasil eksperimen
* Mendokumentasikan proses dan hasil pengerjaan

## Catatan
Repository ini dibuat sebagai bagian dari kegiatan akademik pada mata kuliah **MA3053 Pembelajaran Mesin** dan **IF3270 Pembelajaran Mesin**. Kode, dataset, hasil eksperimen, dan dokumentasi yang terdapat dalam repository disusun berdasarkan kebutuhan masing-masing proyek dan praktikum.

Repository ini juga menjadi bagian dari dokumentasi pembelajaran dan pengembangan kemampuan dalam bidang **Machine Learning, Data Analysis, dan Data Science**.
