# Coffee Shop Sales Dashboard (Excel Project)

Proyek ini mendemonstrasikan analisis penjualan coffee shop menggunakan Microsoft Excel dengan mengolah data transaksi berskala besar hingga mencapai 149.000+ baris data.

### 🔗 Link Dataset & Proyek
- Sumber Data: [Coffee Shop Sales](https://app.mavenanalytics.io/guided-projects/72ec0a0d-bc7d-4ac4-a8da-da811f9061d6#dataset)
- File Excel : [Excel Workbook](https://drive.google.com/drive/folders/1MovUfVGFg8OByewLsmgd4ldoQ_CPDeZT?usp=drive_link)

### 📊 Apa Saja yang Dilakukan?
- Pengolahan Data (Data Cleaning & Preparation)
    Mengelola dan membersihkan data transaksi besar (149k baris) untuk memastikan format tanggal, waktu, dan nominal harga valid.

- Analisis Menggunakan Pivot Table
    Membuat berbagai Pivot Table untuk merangkum data penjualan berdasarkan lokasi toko, waktu transaksi, kategori produk, hingga produk terlaris.

- Pembuatan Dashboard Interaktif
    Membangun visualisasi data yang mencakup:
    - Total Revenue by Month: Tren pendapatan bulanan dari Januari hingga Juni.

    - Transactions by Day of Week & Hour of Day: Analisis pola jam sibuk (peak hours) dan hari teramai kunjungan pelanggan.

    - Transactions by Product Category: Perbandingan volume penjualan di tiap kategori produk.

    - Top 15 Products: Daftar produk unggulan berdasarkan jumlah transaksi dan perolehan revenue.

    - Slicer Lokasi: Filter interaktif untuk membandingkan performa antar cabang (Astoria, Hell's Kitchen, dan Lower Manhattan).
