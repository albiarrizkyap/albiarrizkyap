# Submisi Proyek Bootcamp

Repository ini berisi kumpulan submisi proyek bootcamp dari Coding Camp 2026 powered by DBS Foundation dengan spesialisasi Data Scientist.

Beberapa kelas yang diselesaikan dengan dilakukan proyek sebagai penentu kelulusan di antaranya.
- Belajar Fundamental Analisis Data
- Belajar Machine Learning untuk Pemula
- Belajar Fundamental Pemrosesan Data
- Belajar Matematika untuk Data Science
